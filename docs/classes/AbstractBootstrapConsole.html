    run

    • run(
          argv?: readonly string[],
          parseOptions?: ParseOptions,
      ): Promise<CommandResponse<any> | undefined>

      Init the application, execute the command and close the application.

      Commander errors (unknown command, missing argument...) are already printed by commander, other errors are printed to stderr, and process.exitCode is set (commander's exit code, or 1). The process is not killed, so the application can close its resources (onModuleDestroy...).

      Parameters

      • argv: readonly string[] = process.argv

        The list of arguments to pass to the cli, default are process.argv

      • OptionalparseOptions: ParseOptions

        The commander parse options, eg { from: 'user' } when argv only contains the user arguments

      Returns Promise<CommandResponse<any> | undefined>

      The response of the command, or undefined if it failed
