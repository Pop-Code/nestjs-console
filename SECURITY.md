# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 12.x    | :white_check_mark: |
| 11.x    | :white_check_mark: |
| < 11.0  | :x:                |

## Reporting a Vulnerability

If you found one or more vulnerabilities, please create an issue.
If the review is accepted, we will publish a fix patch.
